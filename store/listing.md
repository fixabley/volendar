`npm run package`를 실행하면 `dist/volendar-<버전>.zip`이 생깁니다. 이 파일을 업로드합니다.

### 간단한 설명 (manifest의 description, 132자 이내)

```
1365·VMS에서 신청한 봉사와 모집 중인 봉사를 한 달력에서 보고 ICS로 내보냅니다.
```

### 자세한 설명

```
1365 자원봉사포털과 VMS(사회복지자원봉사인증관리)에서 신청한 봉사를 한 달력에 모아 보여주는 확장 프로그램입니다.

■ 내 신청 일정
- 두 사이트의 신청 내역을 월간 달력에 표시합니다. 승인(참석가능)된 봉사는 초록색으로 구분합니다.
- 사이트·상태·제목으로 거를 수 있고, 기간을 정하면 봉사시간 합계를 보여줍니다.
- ICS 파일로 내보내 Google 캘린더, Apple 캘린더 등에 넣을 수 있습니다.
- 신청·승인한 봉사의 담당 기관 연락처를 봉사 이름으로 묶어 연락처 파일(.vcf)로 저장할 수 있습니다.

■ 봉사 찾기
- 지역·기간·분야 등으로 두 사이트의 모집 공고를 검색해 날짜별로 펼쳐 보여줍니다.
- 빈 시간 필터: 내 신청 일정이나 내 캘린더(Google·iCloud·Outlook 주소 또는 .ics 파일)와 겹치는 공고를 숨깁니다. 요일별 가능한 시간대, 앞뒤 여유 시간, 바쁜 시간으로 볼 신청 상태도 고를 수 있습니다.
- 1365 기간형 공고는 버튼 한 번으로 실제 신청 가능한 날짜를 확인할 수 있습니다(신청은 하지 않습니다).
- 각 공고의 활동 내용과 담당 기관 연락처를 함께 보여줍니다.

■ 개인정보
- 아이디와 비밀번호를 받지 않습니다. 사용자가 브라우저에서 직접 로그인한 상태에서만 조회합니다.
- 조회한 내용은 브라우저 안에서만 쓰고, 개발자나 다른 곳으로 보내지 않습니다.

■ 알아 두실 점
- 1365·VMS와 관계없는 개인 프로젝트입니다. 사이트 화면 구조가 바뀌면 일부 기능이 동작하지 않을 수 있습니다.
- VMS 공고에는 시간 칸이 없어서, 하루짜리 공고만 본문에 적힌 시간을 추정해 표시합니다.

소스 코드: https://github.com/fixabley/volendar
```

## 개인정보 보호 (Privacy practices)

### 단일 목적 (Single purpose)

```
1365 자원봉사포털과 VMS의 봉사 신청 내역과 모집 공고를 사용자의 일정과 함께 하나의 달력으로 보여주고, ICS로 내보내는 것.
```

### 권한 사용 이유 (Permission justification)

**storage**

```
필터·화면 설정, 사용자가 등록한 캘린더 ICS 주소, 사용자가 불러온 .ics 파일의 일정 시간을 사용자 기기(chrome.storage.local)에 저장합니다.
```

**scripting**

```
브라우저 설정 때문에 확장 페이지의 요청에 1365·VMS 로그인 세션이 실리지 않을 때, 사용자가 열어 둔 1365·VMS 탭 안에서 같은 조회 요청을 한 번 더 보내기 위해 사용합니다. 이 권한은 host_permissions에 있는 두 사이트에만 동작하며, 페이지 내용을 바꾸지 않습니다.
```

**호스트 권한 (https://www.1365.go.kr/*, https://www.vms.or.kr/*)**

```
사용자가 이미 로그인한 세션으로 본인의 봉사 신청 내역을 읽고, 공개된 모집 공고와 상세 정보를 검색하기 위해 필요합니다. 이 두 사이트의 정보를 달력으로 보여주는 것이 확장의 목적입니다.
```

**선택 호스트 권한 (calendar.google.com, *.icloud.com, outlook.live.com, outlook.office365.com, outlook.office.com)**

```
사용자가 '내 캘린더' 기능에 ICS 주소를 직접 등록할 때만, 해당 주소 하나에 대한 권한을 요청합니다. 등록한 캘린더의 일정을 바쁜 시간으로 써서 겹치는 봉사 공고를 숨기는 데 사용합니다.
```

### 원격 코드 (Remote code)

```
아니요. 모든 코드는 패키지 안에 있으며 외부 스크립트를 불러오거나 실행하지 않습니다.
```

### 데이터 사용 (Data usage)

수집 항목은 아래를 체크합니다. 브라우저 안에서만 처리하더라도 다루는 데이터는 밝혀야 하므로, 넓게 체크하는 편이 안전합니다.

- **웹사이트 콘텐츠 (Website content)**
  - 1365·VMS 페이지의 신청 내역과 공고 내용을 읽습니다.
- **개인 식별 정보 (Personally identifiable information)**
  - 공고에 공개된 담당 기관 연락처(전화번호·이메일, VMS는 담당자 이름)를 화면과 ICS에 보여줍니다.
  - 1365 신청서 화면 응답에는 사이트가 미리 채운 사용자 연락처가 들어 있지만, 확장은 이 값을 쓰거나 저장하지 않습니다.

아래 세 가지 확인 항목은 모두 체크합니다.

- 승인된 사용 사례 외에 제3자에게 판매·전송하지 않음
- 단일 목적과 관련 없는 용도로 사용·전송하지 않음
- 신용도 판단이나 대출 목적으로 사용·전송하지 않음
